# Mídia do README

Coloque aqui as imagens e vídeos usados no `README.md` da raiz.

Sugestão de arquivos (referenciados nos placeholders do README):

- `demo.gif` / `demo.mp4` — demonstração principal (hero, topo do README)
- `ui-chat.png`, `ui-jira.png`, `ui-analytics.png` — screenshots da interface
- `fluxo-po-qa.gif` / `fluxo-po-qa.mp4` — fluxo PO → QA de ponta a ponta

Para inserir no README, troque o placeholder correspondente por, ex.:

```html
<p align="center"><img src="docs/media/demo.gif" width="820" alt="Demonstração do Hefesto"></p>
```

Vídeos no GitHub: arraste o arquivo direto na descrição de uma issue/PR para
gerar uma URL `user-images.githubusercontent.com`, ou use a tag `<video>`.
